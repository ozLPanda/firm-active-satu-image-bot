# Satu Image Upload Bot

GUI-бот для актуализации товаров в админке `my.satu.kz`: изображения, цены и статуса наличия.

## Что делает бот

- Читает Excel с эталонными артикулами, названиями, ценами и наличием.
- Ищет изображения в выбранной папке по артикулу товара.
- Проходит по каждому артикулу из Excel, даже если изображения в папке нет.
- На странице списка товаров заранее проверяет, актуальны ли изображение, цена и наличие.
- Не заходит в карточку, если запись уже актуальна.
- Если нужно обновление, открывает карточку товара и синхронизирует поля.
- При наличии новой картинки загружает ее; если картинки нет, обновляет только цену и наличие.
- Если старая картинка уже есть, выносит товар в очередь замены или, в точечном режиме, перезаписывает ее напрямую.
- Ошибки сохранения и загрузки складывает в очередь ручной доработки.

Поддерживаемые форматы изображений: `.jpg`, `.jpeg`, `.png`, `.gif`, `.webp`.

## Требования к Excel

В Excel должны быть колонки с артикулами, названиями и ценой. Поддерживаются заголовки вроде:

- артикул: `Артикул`, `Код`, `Код товара`, `sku`;
- название: `Название`, `Наименование`, `Название позиции`;
- цена: `Цена`, `Розничная цена`, `Цена розничная`, `price`;
- наличие: `Наличие`, `Остаток`, `Статус`, `availability`, `stock`.

Если колонка наличия отсутствует, бот может определить статус из названия:

- `нет в наличии` -> `Нет в наличии`;
- `под заказ` -> `Под заказ`.

Эти слова удаляются из сравниваемого названия товара без учета регистра.

## Артикулы и изображения

Имя файла изображения должно соответствовать артикулу:

```text
00000002146.jpg
00000002146.png
```

Бот сопоставляет артикулы с ведущими нулями и без них. Например, `2146` и `00000002146` считаются одним артикулом.

## Массовый проход

1. Выберите папку с изображениями.
2. Выберите Excel с артикулами, названиями, ценами и наличием.
3. Нажмите `Старт`.
4. При первом запуске войдите в аккаунт satu.kz в открывшемся Chromium.
5. Нажмите `Я авторизован`, если бот ждет подтверждения авторизации.

Бот ищет товары по артикулам, анализирует все найденные записи и страницы выдачи. Если найдено несколько записей по одному артикулу, каждая запись анализируется отдельно.

Если товар уже содержит актуальную картинку, цену и наличие, запись пропускается как актуальная. Это пропуск конкретной записи, а не всего артикула.

## Точечная перезапись по ссылкам

В поле `Точечные ссылки на товары для перезаписи изображений` можно вставить список ссылок, по одной ссылке на строку:

```text
https://my.satu.kz/cms/product/edit/131541514
https://my.satu.kz/cms/product/edit/131541515
```

Также поддерживаются публичные ссылки вида:

```text
https://mstop.kz/p131541514-kollektor-vozd-kom.html
```

Они автоматически преобразуются в:

```text
https://my.satu.kz/cms/product/edit/131541514
```

В ссылке находится ID карточки сайта, а не артикул. Поэтому бот открывает карточку по ссылке, читает артикул из поля `input[data-qaid='sku_input']`, ищет этот артикул в Excel и берет изображение из выбранной папки.

Если среди ссылок остаются адреса не вида `https://my.satu.kz/cms/product/edit/`, бот показывает предупреждение и спрашивает, продолжать ли работу.

## Перезапись существующего изображения

Перед загрузкой новой фотографии бот удаляет старую:

- находит блок изображения `[data-qaid='image_item']`;
- наводит мышь на блок, потому что кнопка удаления появляется только при hover;
- нажимает `[data-qaid='delete_img_btn']`;
- если обычный клик невозможен, использует DOM-click;
- ждет, что изображение исчезло из карточки;
- ждет уведомление сайта об удалении;
- только после этого загружает новое изображение и сохраняет товар.

Если новой фотографии для артикула нет в папке, бот не удаляет существующую фотографию.

## Цена и наличие

Цена берется из колонки `Цена` и записывается в поле:

```html
input[data-qaid="product_price_input"]
```

Наличие выставляется в выпадающем списке карточки товара. Поддерживаются статусы:

- `В наличии`;
- `Нет в наличии`;
- `Под заказ`.

Цена и наличие актуализируются независимо от изображения.

## Кэш и сравнение с прошлым проходом

Бот хранит успешный снимок Excel в:

```text
%LOCALAPPDATA%\SatuImageBot\catalog-cache.json
```

Если включить галочку `Сравнить с предыдущим успешным проходом`, бот сравнит новый Excel с прошлым успешным проходом и покажет таблицу измененных товаров. Пользователь может запустить выбранные строки или все изменения.

Успешно обработанные товары обновляют кэш, чтобы повторный запуск не находил их как новые изменения.

## Очереди ручной доработки

Бот сохраняет очереди в:

```text
%LOCALAPPDATA%\SatuImageBot\existing-images-queue.json
%LOCALAPPDATA%\SatuImageBot\deferred-upload-queue.json
```

В приложении есть кнопки:

- `Прошлые замены` - открыть товары, где нужно решить, заменять ли существующее изображение;
- `Прошлые ошибки` - открыть товары, которые были пропущены из-за ошибки сайта или сохранения.

После успешной ручной обработки запись удаляется из очереди.

## Сохранение путей

Бот запоминает последнюю папку с изображениями и последний Excel:

```text
%LOCALAPPDATA%\SatuImageBot\user-settings.json
```

При запуске пути подставляются только если папка или файл все еще существуют. Если путь больше невалидный, поле остается пустым.

## Отчеты

Отчеты сохраняются в:

```text
%LOCALAPPDATA%\SatuImageBot\reports
```

Файлы:

```text
upload-report-YYYYMMDD-HHMMSS.csv
upload-report-YYYYMMDD-HHMMSS.json
```

Бот хранит не больше 10 последних комплектов отчетов и не больше 10 файлов логирования, чтобы не засорять систему.

## Удобства интерфейса

Во всех полях ввода работают:

- `Ctrl+C`, `Ctrl+X`, `Ctrl+V`, `Ctrl+A`;
- `Shift+Insert`;
- контекстное меню ПКМ: вырезать, копировать, вставить, выделить все.

Горячие клавиши работают и при русской раскладке.

## Запуск из исходников

```powershell
cd C:\Users\admin\Desktop\active-firm\satu_image_bot
python -m pip install -r requirements.txt
python -m playwright install chromium
python .\app.py
```

Chromium использует постоянный профиль:

```text
%LOCALAPPDATA%\SatuImageBot\profile
```

Авторизация satu.kz сохраняется между запусками и пересборками приложения.


## DOM-селекторы

Разметка админки satu.kz может меняться. Основные селекторы находятся в `bot.py` в классе `Selectors`.

Важные текущие селекторы:

- артикул в карточке: `input[data-qaid='sku_input']`;
- цена: `input[data-qaid='product_price_input']`;
- блок изображения: `[data-qaid='image_item']`;
- кнопка удаления изображения: `[data-qaid='delete_img_btn']`;
- кнопка сохранения: `[data-qaid='save_btn']`.
